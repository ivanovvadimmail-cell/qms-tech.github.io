О системе

Что такое АИС СЗН

Полнофункциональная система для органов социальной защиты населения, которая создаёт единое региональное информационное пространство в социальной сфере.

🎯

Назначение

+

Обеспечивает информационную поддержку социального обслуживания граждан и учреждений.

  • Создание единой региональной базы данных в социальной сфере
  • Назначение и оказание мер социальной поддержки гражданам
  • Ведение региональных регистров граждан в рамках единой базы
  • Информатизация сферы социального обслуживания
  • Информационная поддержка специалистов на муниципальном уровне
📊

Масштаб

+

Система работает в масштабах региона и отдельных учреждений.

  • Республика Татарстан — Министерство труда и социальной защиты
  • Финансовые органы СЗН в районах и муниципалитетах
  • Дома-интернаты и центры социального обслуживания
  • Учреждения социального обслуживания различной ведомственной принадлежности
🧩

Модульность

+

Возможность поэтапного внедрения отдельных функциональных модулей.

  • Комплексная региональная информационная система
  • Отдельные функциональные элементы (модули)
  • Поэтапное внедрение с сохранением работоспособности
  • Настройка под региональное законодательство

Функции

Возможности АИС СЗН

Полный охват процессов социальной защиты — от приёма заявлений до назначения и выплаты мер поддержки.

📋

Учёт получателей

+

Единая база данных граждан — получателей мер социальной поддержки.

  • Ведение региональных регистров граждан
  • Учёт льготных категорий
  • История обращений и выплат
  • Сверка данных с федеральными регистрами
  • Персональный учёт семей и детей
💰

Назначение и выплаты

+

Автоматизированное назначение и расчёт мер социальной поддержки.

  • Приём заявлений и формирование дел
  • Расчёт выплат по региональному законодательству
  • Формирование выплатных документов
  • Контроль сроков и объёмов выплат
  • Отчётность по исполнению обязательств
🏥

Социальное обслуживание

+

Информатизация учреждений социального обслуживания.

  • Предоставление услуг социального обслуживания
  • Ведение реестра организаций-поставщиков услуг
  • Информатизация домов-интернатов
  • Работа центров социального обслуживания
  • Учёт граждан, нуждающихся в обслуживании
🔗

Межведомственное взаимодействие

+

Интеграция с федеральными и региональными информационными системами.

  • Пенсионный фонд (ФСД, ЕГИССО)
  • ЗАГС — данные о регистрации актов
  • МФЦ — приём заявлений
  • Организации здравоохранения и образования
  • ЖКХ, транспорт и другие ведомства
♿

Реабилитация и ранняя помощь

+

Информационная поддержка специалистов в сфере реабилитации и ранней помощи.

  • Подсистема «Реабилитация»
  • Встроенный справочник МКФ
  • Межведомственная настройка для задач реабилитации
  • Поддержка специалистов ранней помощи
  • Учёт детей с ограниченными возможностями
📈

Аналитика и отчётность

+

Поисково-аналитические запросы и отчётность для руководства.

  • Несколько вариантов поиска по данным
  • Аналитические выборки и отчёты
  • Статистика по категориям получателей
  • Мониторинг исполнения мер поддержки
  • Выгрузки для вышестоящих органов
Взаимодействие

Интеграция с внешними системами

АИС СЗН обеспечивает информационное взаимодействие с федеральными и региональными информационными системами.

🏛️

Пенсионный фонд

+

Обмен данными с федеральными системами ПФР.

  • ФСД — федеральная социальная доплата
  • ЕГИССО — единая государственная информационная система соцобеспечения
  • Сверка данных о получателях
  • Обмен сведениями о выплатах
📝

ЗАГС

+

Получение сведений о регистрации актов гражданского состояния.

  • Данные о рождении детей
  • Сведения о заключении/расторжении брака
  • Актуализация данных получателей
  • Автоматическая проверка при назначении выплат
🏢

МФЦ

+

Приём заявлений через многофункциональные центры.

  • Приём заявлений на меры поддержки
  • Передача документов в АИС СЗН
  • Уведомление заявителей о статусе
  • Единое окно для граждан
🏥

Здравоохранение

+

Обмен данными с организациями здравоохранения.

  • Сведения о состоянии здоровья
  • Данные для установления инвалидности
  • Информация для МСЭ
  • Взаимодействие по реабилитации
🎓

Образование

+

Взаимодействие с организациями образования.

  • Данные о детях школьного возраста
  • Сведения для выплат на детей
  • Информация о посещении образовательных учреждений
  • Поддержка семей с детьми
🏠

ЖКХ и транспорт

+

Обмен данными для предоставления льгот.

  • Сведения о жилищных условиях
  • Данные для субсидий на ЖКХ
  • Транспортные льготы
  • Проверка права на меры поддержки
